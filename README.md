# 🐶🐩💞 오늘의 강아지 - 실시간 근태 현황 조회 및 강아지 포토 갤러리

날짜별 근태 현황을 실시간으로 조회하고, 강아지 포토 갤러리, 실시간 댓글 시스템 및 임직원 근태 현황을 효율적으로 모니터링할 수 있는 모던 대시보드 웹 서비스입니다.

---

## 📌 주요 기능 (Key Features)

- 🐶 **오늘의 강아지 테마 & SVG Favicon (`🐶`)**
  - 귀여운 강아지 파비콘과 모던 대시보드 테마 적용

- 💬 **Supabase DB 연동 실시간 댓글 & 대댓글 시스템 (Comments & Replies)**
  - **계층형 대댓글 구조 (`parent_id`)**: 답글 클릭 시 특정 댓글에 1단계 들여쓰기(`↳`) 계층형 대댓글 작성 지원
  - **실시간 댓글 사이드바 카드 (`💬 실시간 댓글`)**: '오늘의 식단' 하단 위치, 최신 댓글 10개 단위 노출, +5개 더보기 및 개별 새로고침 기능 지원
  - **스마트 댓글 바로가기**: 실시간 댓글 클릭 시 해당 사진의 상세보기 모달창 즉시 오픈
  - **댓글 좋아요 (`❤️`) & 개별 삭제 (`🗑️`)**: 댓글별 독립적 좋아요 카운터 및 삭제 기능

- 🛡️ **지능형 조건부 댓글 삭제 (Smart Soft Delete)**
  - 댓글 삭제 시 DB 물리 삭제 대신 **Soft Delete (`is_deleted = true`, `comment = '삭제된 댓글입니다'`)** 수행
  - **계층 보존 정책**: 하위에 활성화된 대댓글이 존재하는 부모 댓글은 `"🗑️ 삭제된 댓글입니다"` 라인을 유지하여 계층 구조 보호
  - **재귀적 투명 숨김 (`hasActiveDescendants`)**: 하위 대댓글이 없거나 모든 대댓글이 삭제된 경우, `"삭제된 댓글입니다"` 라인도 노출하지 않고 화면에서 완전히 숨김
  - **정확한 통계 집계**: 갤러리 썸네일 오버레이 뱃지(`💬 댓글 수`) 및 실시간 댓글 사이드바에서 삭제된 댓글 카운트 완전 차감

- 📸 **Supabase DB 연동 강아지 포토 갤러리 (Photo Gallery)**
  - **Supabase DB (`gallery_photos`)**와 연동된 이미지 업로드, 삭제 및 순서 저장 관리
  - **실시간 반응형 슬라이딩 카러셀**: 썸네일 사진 위 **반투명 블랙 뱃지 (`❤️ 좋아요  💬 댓글 수`)** 실시간 오버레이 표시
  - **전체보기 관리 모달 (`galleryManageModal`)**: 등록 사진 4:3 프레임 조회, 순서 변경 (`▲`/`▼`), 삭제 (`🗑️`)
  - **와이드 상세 이미지 모달 (`photoPreviewModal`)**:
    - 넓어진 와이드 모달 레이아웃(`max-w-3xl`) 적용으로 댓글 장문 시인성 극대화
    - 사진 이동 화살표 버튼을 **이미지 박스 바깥 양옆**으로 배치하여 사진 가림 방지
    - 댓글 입력창 키보드 조작 시 불필요한 슬라이드 이동 방지
  - **내림차순 정렬 (`display_order.desc, id.desc`)**: 신규 이미지에 `display_order + 10` 자동 부여로 최신 사진 상단 배치
  - **2.5MB 전송 자동 다이어트 (Auto-Compression Loop)**: Canvas 자동 압축으로 Vercel Serverless 4.5MB 제한 완벽 준수

- 📐 **접이식 사이드바 카드 (Collapsible Cards)**
  - **날짜 선택 카드** 및 **오늘의 식단 카드**가 초기 진입 시 기본적으로 접힘(`Collapsed`) 상태로 정돈되어 깔끔한 뷰 제공

- 👥 **팝업 모달 방식의 '우리 편 관리' (추가 / 삭제 / 복원)**
  - `✏️ 우리 편 관리` 연필 버튼 클릭 시 팝업 모달창(`trackedEmpModal`)으로 직관적 조회 및 편집
  - `localStorage` 보관 및 초기 7인 원클릭 복원 기능 제공

- 📊 **덤으로 보는 카드 태깅 현황 (임직원 근태 현황 요약)**
  - 상태(`🟢 출근` / `🔴 미태깅`), 사번, 카드번호, 첫태깅, 끝태깅, 태깅 횟수, 주요 위치 파악
  - 요약 행 클릭 시 해당 직원의 상세 태깅 내역 하단 필터링

- 📋 **태깅 상세 내역 표**
  - 순번, 이름, 사번, 카드번호, 태깅 일시, 장치명(`devNm`) 정보 제공 및 실시간 통합 검색 (이름, 사번, 카드ID, 장치명)

- 🔒 **아이콘 전용 관리자 인증 버튼 (`🔒` / `🔓`)**
  - 자물쇠 아이콘 토글 버튼 (인증 시 2시간 조회 유지)

- ☀️🌙 **라이트 모드 & 다크 모드 지원**
  - 현대적인 모던 라이트 테마 기본 적용 및 원클릭 다크모드 전환

## 🛠️ 기술 스택 (Tech Stack)

### Frontend
- **Languages / Frameworks**: HTML5, CSS3, JavaScript (ES6+ Vanilla JS)
- **Styling**: Tailwind CSS, Custom CSS Variables (Light/Dark Theme)
- **Icons & Graphics**: FontAwesome 6.4.0, SVG Emoji Favicon (`🐶`)

### Backend & Database
- **Runtime**: Node.js (v20+)
- **Framework**: Express.js
- **Database**: Supabase PostgreSQL (`gallery_photos`, `gallery_comments` PostgREST API 연동)
- **HTTP Client**: Axios
- **Deployment Platform**: Vercel Serverless Functions (`api/photos.js`, `api/attendance.js` 등)

## 🗄️ 데이터베이스 테이블 구조 (Supabase DB DDL)

### 1. `gallery_photos` (갤러리 이미지 저장소)
```sql
CREATE TABLE IF NOT EXISTS gallery_photos (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  url TEXT NOT NULL,
  title TEXT,
  display_order INT DEFAULT 0,
  like_count INT DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 2. `gallery_comments` (댓글 & 대댓글 저장소)
```sql
CREATE TABLE IF NOT EXISTS gallery_comments (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  photo_id BIGINT REFERENCES gallery_photos(id) ON DELETE CASCADE,
  writer TEXT DEFAULT '익명 강아지',
  comment TEXT NOT NULL,
  parent_id BIGINT REFERENCES gallery_comments(id) ON DELETE CASCADE,
  like_count INT DEFAULT 0,
  is_deleted BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- UPDATE 및 DELETE RLS 정책 추가
CREATE POLICY "Allow public update access to gallery_comments" ON gallery_comments FOR UPDATE USING (true) WITH CHECK (true);
```

## 🔐 환경 변수 설정 (Environment Variables)

Vercel 배포 시 **Project Settings ➔ Environment Variables**에 아래 환경 변수를 등록하여 관리합니다:

| 환경 변수 명 | 설명 |
| :--- | :--- |
| `ATTENDANCE_API_CODE` | API 요청 헤더 `code` |
| `ATTENDANCE_API_KEY` | API 요청 헤더 `key` |
| `SUPABASE_URL` | Supabase 프로젝트 URL (`https://<project-id>.supabase.co`) |
| `SUPABASE_KEY` | Supabase API key (`anon` 또는 `service_role` 키) |
| `ADMIN_KEY` | 관리자 화면 해제 비밀번호 (`[🔒]` 버튼) |

## 🚀 시작하기 (Getting Started)

### 1. 리포지토리 클론 및 패키지 설치
```bash
git clone https://github.com/kimkongzzak/attendance.git
cd attendance
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm start
```
서버 실행 후 브라우저에서 `http://localhost:3000` 으로 접속합니다.
